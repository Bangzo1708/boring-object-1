A one-line review of the most boring object imaginable — the coaster: hired to save the table from rings, it spends its life collecting them from the very mugs it was meant to stop. Three candidate lines (coaster, doorstop, tea towel) were drafted and scored on dullness, truth, punch and originality; the coaster won on all four. Running `main.ts` writes the winning line to `/output/entry.txt`.
